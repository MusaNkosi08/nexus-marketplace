# MET4 Assignment 2 Rubric Notes

The brief requires a cross-platform application with Angular as the web frontend, React Native as the mobile frontend, Express.js as the backend API, and MongoDB or MySQL as the database. The project theme can be an e-commerce platform, which matches NEXUS.

The React Native deliverable requires bottom tabs or equivalent navigation with a minimum of four tabs such as Home, Categories, Cart, and Profile. It must fetch data from the Express API, include a cart page with item list and total, and include search and settings components.

The web deliverable requires an Angular project using Bootstrap, with at least five pages: Home, Item List, Item Detail, Cart, and Admin Panel. It must fetch data from the backend API, and the admin panel must support add, edit, and delete with form validation.

The backend deliverable requires Express.js, JWT user authentication, bcrypt password hashing, at least four CRUD endpoints including GET /items, POST /items, PUT /items/:id, and DELETE /items/:id, login and registration routes, and MongoDB or MySQL.

Deliverables require a separate mobile folder and a folder containing frontend and backend projects. Documentation must include screenshots of web and mobile UI plus mood boards. Submission requires a zip named GroupName_Project.zip with node_modules excluded.

The assessment weights are 40 marks for mobile, 40 for web, 40 for backend, 15 for web/mobile integration, and 15 for documentation and structure.
