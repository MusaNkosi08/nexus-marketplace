# NEXUS Editorial Mood Board

## Creative direction

NEXUS is positioned as a premium technology marketplace with an editorial, highly curated voice. The interface should feel closer to a modern independent magazine than a conventional electronics catalogue: generous cream space, confident dark typography, restrained red emphasis, and blue utility accents create a distinctive South African technology retail identity.

## Palette

| Token | Hex | Intended role |
|---|---:|---|
| Transparent Yellow | `#F5EFC6` | Primary canvas, warm editorial paper, light screen backgrounds |
| Sceptre Red | `#4D0E12` | Editorial labels, selected states, high-attention actions |
| Cerulean Blue | `#A5BCD6` | Utility accents, focus states, secondary surfaces |
| Potting Soil | `#4A2E27` | Long-form text, supporting copy, warm contrast |
| Java Brown | `#231815` | Navigation, hero contrast, primary action surfaces |

## Material and composition cues

The visual language combines warm paper-like fields with dark ink-like navigation and product photography that remains the focal point. Layouts favor asymmetric editorial grids, oversized headlines, compact metadata, thin dividers, and quiet hover/press feedback. Product cards should read as curated objects rather than generic inventory tiles.

## Cross-client application

The React storefront uses the full editorial system for the public shopping experience. The Bootstrap Angular companion preserves the same hierarchy through a responsive navbar, catalogue cards, cart summary, and admin controls. The Expo mobile client maps the same palette to Home, Categories, Cart, Profile, product detail, the shared screen container, and the tab layout, with NativeWind tokens available through the root stylesheet.

## Submission note

This mood board is a design reference rather than fabricated customer feedback or generated product endorsement. Product imagery and catalogue content remain sourced from the implemented catalogue data.
